# 🌐 WebVoyager — AI Browser Agent

**WebVoyager** is an AI-powered browser automation tool that intelligently understands web content and performs actions dynamically — just like a human user.  
It automates repetitive web tasks such as form filling, button clicking, and multi-page data extraction, all powered by modern AI 

---

## 🚀 Features
- 🤖 **AI Understanding:** Analyzes webpage content and takes intelligent actions.
- 🧭 **Dynamic Navigation:** Handles complex, multi-page flows automatically.
- ⚙️ **Automation:** Automates form filling, clicks, and data extraction.

---

## 🛠️ Tech Stack
- **Backend:** Python,  
- **AI Model:** Gemini / LLM Integration   
- **Automation:** Playwright  
- **Frontend :** React / Next.js
